Part 1.4 — Iterative Denoising

I implemented iterative denoising using strided timesteps (starting from 990, with stride 30, reaching 0). This allows for gradual, step-by-step denoising that produces better results than one-step denoising.

Part 1.5 — Diffusion Model Sampling

I generated images from pure noise using iterative denoising with the prompt "a high quality photo". Starting from random noise, the model gradually refines it into a coherent image.

5 Sampled Images from Pure Noise

Part 1.6 — Classifier-Free Guidance (CFG)

I implemented Classifier-Free Guidance to improve image quality. CFG works by computing both a conditional and unconditional noise estimate, then extrapolating away from the unconditional estimate. I used a guidance scale of γ = 7.

5 Sampled Images with CFG (γ = 7)

Part 1.7 — Image-to-Image Translation

Using the SDEdit algorithm, I took real images, added noise to them, and then denoised with the diffusion model. By starting the denoising process at different noise levels, we can control how much the output differs from the input.
