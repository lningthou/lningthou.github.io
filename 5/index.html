Conversely, for the Neon City prompt, higher steps resulted in excessive saturation and sharpness. The lower step count 10 produced a softer, more photorealistic effect.

Part 1.1: Implementing the Forward Process

I implemented the forward(im, t) function which adds noise to a clean image according to the diffusion forward process equation. The amount of noise depends on the timestep t, with higher timesteps adding more noise.

def forward(im, t):
    with torch.no_grad():
        noise = torch.randn_like(im)
        im_noisy = torch.sqrt(alphas_cumprod[t]) * im + torch.sqrt(1 - alphas_cumprod[t]) * noise
    return im_noisy

Part 1.4: Iterative Denoising

I implemented iterative denoising using strided timesteps (starting from 990, with stride 30, reaching 0). This allows for gradual, step-by-step denoising that produces better results than one-step denoising.

strided_timesteps = list(range(990, 0, -30)) + [0]
def iterative_denoise(im_noisy, i_start, prompt_embeds, timesteps, display=True):
    image = im_noisy

    with torch.no_grad():
        for i in range(i_start, len(timesteps) - 1):
            t = timesteps[i]
            prev_t = timesteps[i+1]

            alpha_cumprod = alphas_cumprod[t]
            alpha_cumprod_prev = alphas_cumprod[prev_t]
            alpha = alpha_cumprod / alpha_cumprod_prev
            beta = 1 - alpha

            model_output = stage_1.unet(
                image, t, encoder_hidden_states=prompt_embeds, return_dict=False
            )[0]

            noise_est, predicted_variance = torch.split(model_output, image.shape[1], dim=1)

            x0 = (image - torch.sqrt(1 - alpha_cumprod) * noise_est) / torch.sqrt(alpha_cumprod)
            term1 = torch.sqrt(alpha_cumprod_prev) * beta / (1 - alpha_cumprod) * x0
            term2 = torch.sqrt(alpha) * (1 - alpha_cumprod_prev) / (1 - alpha_cumprod) * image
            pred_prev_image = term1 + term2 + (add_variance(predicted_variance, t, image) - image)

            image = pred_prev_image

        clean = image[0].cpu().detach().permute(1, 2, 0) / 2.0 + 0.5
    return clean

Part 1.6: Classifier-Free Guidance (CFG)

I implemented Classifier-Free Guidance to improve image quality. CFG works by computing both a conditional and unconditional noise estimate, then extrapolating away from the unconditional estimate. I used the prompt "a high quality picture" with a guidance scale of γ = 7.

def iterative_denoise_cfg(im_noisy, i_start, prompt_embeds, uncond_prompt_embeds,
                          timesteps, scale=7, display=True):
    image = im_noisy

    with torch.no_grad():
        for i in range(i_start, len(timesteps) - 1):
            t = timesteps[i]
            prev_t = timesteps[i+1]

            alpha_cumprod = alphas_cumprod[t]
            alpha_cumprod_prev = alphas_cumprod[prev_t]
            alpha = alpha_cumprod / alpha_cumprod_prev
            beta = 1 - alpha

            # Get conditional and unconditional noise estimates
            model_output = stage_1.unet(
                image, t, encoder_hidden_states=prompt_embeds, return_dict=False
            )[0]
            uncond_model_output = stage_1.unet(
                image, t, encoder_hidden_states=uncond_prompt_embeds, return_dict=False
            )[0]

            noise_est, predicted_variance = torch.split(model_output, image.shape[1], dim=1)
            uncond_noise_est, _ = torch.split(uncond_model_output, image.shape[1], dim=1)

            # CFG: extrapolate away from unconditional estimate
            noise_est = uncond_noise_est + scale * (noise_est - uncond_noise_est)

            x0 = (image - torch.sqrt(1 - alpha_cumprod) * noise_est) / torch.sqrt(alpha_cumprod)
            term1 = torch.sqrt(alpha_cumprod_prev) * beta / (1 - alpha_cumprod) * x0
            term2 = torch.sqrt(alpha) * (1 - alpha_cumprod_prev) / (1 - alpha_cumprod) * image
            pred_prev_image = term1 + term2 + (add_variance(predicted_variance, t, image) - image)

            image = pred_prev_image

        clean = image[0].cpu().detach().permute(1, 2, 0) / 2.0 + 0.5
    return clean

Part 1.7.2: Inpainting

I implemented inpainting by creating a binary mask and using the diffusion model to fill in the masked region while keeping the rest of the image intact.

The inpaint function is similar to iterative_denoise_cfg with the key difference being that after each denoising step, we blend the denoised result with the original image using the mask:

def inpaint(original_image, mask, i_start, prompt_embeds, uncond_prompt_embeds,
            timesteps, scale=7, display=True):
    image = torch.randn_like(original_image).to(device).half()

    with torch.no_grad():
        for i in range(i_start, len(timesteps) - 1):
            # ... same CFG denoising as iterative_denoise_cfg ...
            # Key difference: after computing pred_prev_image, blend with original
            if i < len(timesteps) - 2:
                image = mask * pred_prev_image + (1 - mask) * forward(original_image, prev_t)
            else:
                image = mask * pred_prev_image + (1 - mask) * original_image

        clean = image[0].cpu().detach().permute(1, 2, 0) / 2.0 + 0.5
    return clean

Part 1.8: Visual Anagrams

I implemented visual anagrams - optical illusions that show different images depending on orientation. I denoise with one prompt, flip the image, denoise with another prompt, flip back, and average the noise estimates.

The make_flip_illusion function extends CFG denoising to use two prompts—one for the upright image and one for the flipped version:

def make_flip_illusion(image, i_start, prompt_embeds, uncond_prompt_embeds,
                       timesteps, scale=7):
    p1_embeds = prompt_embeds[0:1]  # First prompt (upright)
    p2_embeds = prompt_embeds[1:2]  # Second prompt (flipped)

    with torch.no_grad():
        for i in range(i_start, len(timesteps) - 1):
            # ... compute alpha_cumprod, alpha, beta as before ...

            # CFG noise estimate for upright image with prompt 1
            eps_1 = uncond_noise_est_1 + scale * (noise_est_1 - uncond_noise_est_1)

            # Flip image, get CFG noise estimate with prompt 2, flip back
            flipped_image = torch.flip(image, [2])
            # ... get model outputs for flipped image with p2_embeds ...
            eps_2_flipped = uncond_noise_est_2 + scale * (noise_est_2 - uncond_noise_est_2)
            eps_2 = torch.flip(eps_2_flipped, [2])

            # Average the two noise estimates
            noise_est = (eps_1 + eps_2) / 2.0

            # ... continue with DDPM step using averaged noise_est ...
    return clean

Part 1.9: Hybrid Images

I created hybrid images by combining the low frequencies from one denoised image with the high frequencies from another. The result shows different images depending on viewing distance.

The make_hybrids function is similar to visual anagrams but instead of flipping, it extracts low frequencies from one prompt's noise estimate and high frequencies from another:

def make_hybrids(image, i_start, prompt_embeds, uncond_prompt_embeds,
                 timesteps, scale=7):
    p1_embeds = prompt_embeds[0:1]  # Low-frequency prompt
    p2_embeds = prompt_embeds[1:2]  # High-frequency prompt

    with torch.no_grad():
        for i in range(i_start, len(timesteps) - 1):
            # ... compute alpha_cumprod, alpha, beta as before ...

            # CFG noise estimates for both prompts
            eps_1 = uncond_noise_est_1 + scale * (noise_est_1 - uncond_noise_est_1)
            eps_2 = uncond_noise_est_2 + scale * (noise_est_2 - uncond_noise_est_2)

            # Extract low frequencies from eps_1, high frequencies from eps_2
            eps_low = gaussian_blur(eps_1, kernel_size=33, sigma=2)
            eps_2_blurred = gaussian_blur(eps_2, kernel_size=33, sigma=2)
            eps_high = eps_2 - eps_2_blurred

            # Combine low and high frequency components
            noise_est = eps_low + eps_high

            # ... continue with DDPM step using combined noise_est ...
    return clean
