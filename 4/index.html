Model Architecture Report

For this part I created a Multilayer Perceptron (MLP) network with Sinusoidal Positional Encoding (PE) that takes in the 2-dim pixel coordinates and outputs the 3-dim pixel colors. Below is an image and table detailing the architecture.

Layers 4 fully-connected layers (3 hidden + 1 output):
Linear(42->256) → ReLU → Linear(256->256) → ReLU → Linear(256->256) → ReLU → Linear(256->3) → Sigmoid
Width256
Learning Rate1e-2
PE L = 10 -> input dimension = 2 + 4L = 42 (original x & y plus sin/cos terms for both x & y)
