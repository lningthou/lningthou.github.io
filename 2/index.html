Fun with Filters & Frequencies

Part 1 — Fun with Filters

Part 1.1 — Convolutions from Scratch!

My convolution functions take in an image and a kernel. First, the kernel (kw x kh) is flipped horizontally and vertically. Next, the image is padded by (kw - 1)/2 zeros on the left/right and by (kh - 1)/2 zeros on the top/bottom. Finally, we slide the kernel across each valid position of the padded image and write each weighted sum to the corresponding position of the output image.

The four loop implementation loops across each valid row/column pair of the padded image that acts as the center for the kernel in the current slide. An additional two loops are used to multiply the row/column pairs of the kernel and the corresponding window of the padded image and accumulate the sum we write to the output image. The four loop implementation can be seen below:


def convolve_4(image, kernel):
    kernel = np.flipud(np.fliplr(kernel))
    pad_y, pad_x = (kernel.shape[0]-1)//2, (kernel.shape[1]-1)//2
    padded_image = np.pad(image, pad_width=((pad_y, pad_y), (pad_x, pad_x)), mode='constant', constant_values=0)
    output_image = np.zeros((image.shape[0], image.shape[1]))
    for row in range(pad_y, padded_image.shape[0] - pad_y):
        for col in range(pad_x, padded_image.shape[1] - pad_x):
        total_sum = 0
        for i in range(row - pad_y, row + pad_y + 1):
            for j in range(col - pad_x, col + pad_x + 1):
            total_sum += padded_image[i, j] * kernel[i - (row - pad_y), j - (col - pad_x)]
        output_image[row - pad_y, col - pad_x] = total_sum
    return output_image

In the two loop implementation we still need to loop across the row/column pairs that act as kernel centers, but we can eliminate the use of more loops by using numpy builtins to directly compute np.sum(np.multiply(sub_image, kernel)). The two loop implementation can be seen below:


def convolve(image, kernel):
    kernel = np.flipud(np.fliplr(kernel))
    pad_y, pad_x = (kernel.shape[0]-1)//2, (kernel.shape[1]-1)//2
    padded_image = np.pad(image, pad_width=((pad_y, pad_y), (pad_x, pad_x)), mode='constant', constant_values=0)
    output_image = np.zeros((image.shape[0], image.shape[1]))
    for row in range(pad_y, padded_image.shape[0] - pad_y):
        for col in range(pad_x, padded_image.shape[1] - pad_x):
        sub_image = padded_image[(row - pad_y):(row + pad_y + 1), (col - pad_x):(col + pad_x + 1)]
        output_image[row - pad_y, col - pad_x] = np.sum(np.multiply(sub_image, kernel))
    return output_image

The four loop implementation is slower than the two loop implementation because its inner two loops run in Python, whereas the two loop version uses NumPy ufuncs that execute the inner work in vectorized C. Both are still slower than scipy.signal.convolve2d, which is implemented in highly optimized C with cache-friendly loops. However, all three produce the same output visually.

Part 1.2 — Finite Difference Operator

I compute the partial derivatives of the cameraman image by convolving it with the finite difference operators Dx and Dy. The gradient magnitude is computed with the formula sqrt(Dx^2 + Dy^2). Finally, a binarized edge image is created by thresholding the gradient magnitude image such that any pixel with a value greater than 0.32 is set to 1 and the rest to 0. The value of 0.32 was chosen (experimentally) as it preserved most of the edges of the cameraman but eliminated most of the noise coming from the buildings in the background and the grass. Part 2 — Fun with Frequencies

Part 2.1 — Image “Sharpening” (Unsharp Mask)

We can get the low frequencies of an image by convolving it with a gaussian filter L = I * G. We can get the high frequencies by subtracting L from the original image H = I - L. To sharpen the original image, we add H scaled by a factor α to the original image S = I + αH. Expanding this out:


S = I + α(I - I * G)
S = (1 + α)I - α(I * G)
S = I * ((1+α)δ) - I * (αG) [I = I * δ where δ is the identity kernel]
S = I * ((1+α)δ - αG)

The unsharp mask filter is then K = ((1+α)δ - αG).

Part 2.3 — Gaussian & Laplacian Stacks

To blend two images, Gaussian and Laplacian stacks come in handy. A Gaussian stack progressively blurs the image, while a Laplacian stack stores band-pass detail as L_i = G_i − G_{i+1} with the final level being L_n = G_n. To blend two images, we create a mask and then a Gaussian stack for each image and the mask. Then, we create a Laplacian stack for each image. A key property is that adding all Laplacian levels recovers the original image. We exploit this by forming the blended Laplacian for each level i: L_blend_i = GM_i * LA_i + (1 − GM_i) * LB_i, where GM_i is the mask’s Gaussian level and * is element-wise multiplication. Finally, we reconstruct the blended image by summing the blended Laplacian levels.
